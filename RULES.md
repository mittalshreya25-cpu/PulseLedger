# PulseLedger Rules & Guidelines

1. **Integer Paise for Currency**: All monetary amounts are stored and handled strictly as integer paise (1 INR = 100 paise). Floating-point currency calculations are prohibited.
2. **Python Computes Numbers**: The LLM never computes numbers, arithmetic, or financial balances directly; only deterministic Python code computes numbers.
3. **Engine Test Coverage**: Every engine function must have a corresponding pytest verifying its logic and edge cases.
4. **No Securities Recommendations**: Never recommend specific securities, stocks, funds, or speculative investment vehicles.
5. **Task Discipline**: Work on one task at a time and stop after each task.
